# Cloud Mapping

| Local Environment    | Google Compute Engine               |
| -------------------- | ----------------------------------- |
| Ubuntu               | Compute Engine Ubuntu VM            |
| Local machine        | VM Instance                         |
| Local IP address     | External/static IP address          |
| Local PostgreSQL     | PostgreSQL on VM                    |
| Local filesystem     | Persistent disk                     |
| Local Flask app      | Flask app running on VM             |
| Local Gunicorn       | Gunicorn running on VM              |
| Local port `5000`    | Firewall rule / exposed port        |
| `localhost`          | VM external IP                      |
| Local `.env`         | VM environment variables            |
| `systemctl`          | `systemctl` on the VM               |
| Local terminal / SSH | SSH into Compute Engine VM          |
